## Step 1: Talk to the User Until Understanding Matches, Before Doing Any Work

Before starting any task, keep talking with the user — asking and clarifying back and forth — until the AI's understanding and the developer's intent are truly aligned. Do not start doing the actual work until that shared understanding is confirmed. Skip this only if the user explicitly says to just go ahead without discussion, or the task is trivial and fully specified already.
